# 08 — Roadmap & Phase Gates

## Phase 0 — Foundation

Deliver product specification, architecture, domain model, security contract, UX flow, test strategy, and implementation prompt.

**Gate:** terminology and Runner Core are unambiguous.

## Phase 1 — Runner Core MVP

Build authentication, Run CRUD, lifecycle state machine, next action, progress, blockers, events, and Today dashboard.

**Gate:** complete Run lifecycle works end-to-end.

## Phase 2 — Productivity

Projects, tasks, goals, daily focus, and focus sessions built on Core.

**Gate:** productivity features do not create a second competing execution model.

## Phase 3 — Activities & Hobbies

Custom activities, fitness/activity records, history, and flexible activity-to-Run relationships.

**Gate:** at least two materially different activity types work without special-casing the Core.

## Phase 4 — Integrations

Implement connector framework and Strava first. Add calendar/GitHub only after the connector contract is proven.

**Gate:** sync is secure, idempotent, observable, and recoverable.

## Phase 5 — Intelligence

Add optional AI assistance for capture, clarification, planning, summaries, and recovery suggestions.

**Gate:** AI remains an assistive layer and does not weaken ownership or safety controls.

## Phase 6 — Validation & Expansion

Observe real usage, identify the highest-value workflow, and only then expand modules or monetization.
